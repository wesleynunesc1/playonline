# Play Online

Regras do Projeto:
1. **Versionamento e Deploy:**
   - Ao finalizar alterações e tarefas em cada comando, realizar `git add .`, `git commit -m "..."` e sincronizar com o repositório remoto (`git push origin main`).
   - Se o projeto estiver conectado na Vercel via GitHub, o push para a branch `main` executa o deploy de produção automaticamente. Caso seja utilizado o CLI da Vercel, executar o deploy em produção (`npx.cmd vercel --prod`).

2. **Código Limpo e Otimizado:**
   - Criar código enxuto, limpo e direto ao ponto, evitando códigos duplicados, dependências pesadas e redundâncias.
   - Garantir boa performance sem arquivos desnecessários para não ocupar espaço nem causar lentidão/travamentos.
